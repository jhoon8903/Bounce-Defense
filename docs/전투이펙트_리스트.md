## 0. 시작 전에 알아야 할 3가지

1. **CFXR은 그대로 쓸 수 있다.** 이 프로젝트는 URP 17.3(Unity 6)이고, Cartoon FX Remaster는 URP+Built-in 겸용 셰이더로 배포됨. 셰이더 포팅 불필요, URP 변형만 임포트. (흰색 피격 플래시가 이미 URP 스프라이트 셰이더 `SpriteHitFlash`를 쓰고 있음 = URP 파티클도 문제없음.)

2. **9개 중 2개는 "파티클"이 아니라 "코드 모션"이다.** #4(피격 움찔), #8(발사 시 캐릭 까딱)은 CFXR 프리팹이 아니라 **애니메이션 코드**로 만든다. 이 코드베이스는 의도적으로 Animator/DOTween 없이 `IClock.GameDeltaTime`으로 손튜닝한 감쇠 트윈을 씀(예: `DamageTextView.Tick`, `EnemyView.SetSquash`). 즉 이 두 개는 "프리팹 붙이기"가 아니라 "감쇠 트윈 한 개 짜기".

3. **대부분의 이펙트는 파티클을 붙이기 전에 작은 이벤트 훅을 먼저 열어야 한다.** 지금 전투 코드가 쏘는 이벤트는 `OnHit`(위치+크리티컬 O), `OnKill`(**위치 X**), `OnBreach`뿐. 죽음 위치·발사 순간·피격 방향·번/냉동 시작·레이저 행 좌표 등을 실어나르는 훅이 없어서 이걸 여는 게 실제 작업량의 절반. (§4 참조)

## 4. 먼저 열어야 할 이벤트 훅 (구현 순서 = 이 순서 권장)

한 번 열면 여러 이펙트가 여기 얹힘. **훅 → 프리팹 순으로** 작업.

1. **`OnEnemyDeath(Vector2 pos)`** (또는 `RaiseKill`에 위치 추가) — `EnemyController.cs:119`. `deathPos`는 이미 로컬에 캡처됨, 방송만 안 함. → #3, #5 해금.
2. **`OnBallFired(Vector2 origin)`** — `BallController.cs:137`. → #8, #9, 머즐(T3). 발사 이벤트가 아예 없음.
3. **`OnHit`에 `Vector2 hitDir` 추가** — normal이 `BallController.cs:236`에 있는데 버려짐. → #4.
4. **`OnBurnStart/End` (적 단위)** — `EnemyStatusSimulator`(ApplyBurn:26 / 만료 Tick:107). → #6.
5. **레이저 행 스폰** — `BallController.DamageEnemyRow`(cs:77). 좌표는 `GridModel.CellToWorld`로 이미 조회 가능(행Y = 1.27 + (6-row)·1.0, 폭 9, x=0 중심). → #7.
6. **`OnExplosion(center,radius)`** — `EnemyController.TryLastMatchExplosion`(cs:126). → #5 버스트.
7. (선택) **`OnWallBounce(pos,normal)`** — 지금 벽튕김은 내부(`_mirrorArmed`)만. → Mirror 신호(T2), 바운스 스파크(T3).

**공통 인프라:** `HitFeedbackController`가 `OnHit`+`IClock.OnTick` 구독하는 단일 피드백 오케스트레이터 = 새 파티클/움찔 티커의 자연스러운 집. `Pool<T>` 풀링 이미 `DamageTextView`+6볼타입에 사용 중 = 풀드 파티클도 재사용.

## 5. 결정 필요 3가지 (구현 전 선택)

### ① #9 마법진 타이밍 — 코스메틱 vs 진짜 선딜
**문제:** 볼은 Staff 끝이 아니라 **Char 몸통 원점**에서 나감(`LaunchController.Origin`), 스태프 끝 트랜스폼도 없음. 게다가 발사는 **즉발**(선딜 0)이라 "마법진 생겼다가 발사"의 '먼저' 구간이 없음.
- **A) 코스메틱 플래시** — 발사 순간 스태프/몸통에 마법진 원샷 팝, 선딜 없음. 연사 손맛 유지. `StaffTip` 자식만 추가.
- **B) 진짜 윈드업** — `StaffTip` + 짧은 선딜(예: 0.1~0.15초)로 마법진 생성→발사 순서 진짜 연출. 연출 좋지만 **연사 텀에 선딜이 끼어 손맛이 달라짐**.
- 되돌리기: 쉬움(연출/타이밍). → 일단 A로 진행하고 플레이 느낌 보고 B 검토 권장.

### ② 냉동(Freeze) 오버레이 — CFXR에 상시 얼음 루프가 없음
**문제:** Ice 카테고리 프리팹이 원샷 1개뿐. "얼음 붙은 채로 하강" 상시 시각이 없음.
- **A) 컬러 틴트(최저비용)** — 기존 `MaterialPropertyBlock`(피격 플래시 경로 재사용)으로 block+mob을 시안으로 물들임. 코드 몇 줄.
- **B) 정적 서리 스프라이트 오버레이** — 적 자식에 반투명 서리 스프라이트 부착(#6 번 오버레이와 같은 패턴).
- **C) 전기 개조** — `CFXR Electrified 1`을 시안 틴트해 "얼음 크래클"로 전용.
- 권장: **A + B**(시안 틴트 + 옅은 서리 스프라이트), 적용 순간 스플래시만 `Hit Ice B`. 되돌리기 쉬움.

### ③ 정렬 레이어 — "VFX" 레이어 추가 vs order 밴드만
**문제:** TagManager에 정렬 레이어가 **"Default" 하나뿐**. 지금은 order 숫자로만 층 구분(BG -100 / 트레일 -1 / 볼·캐릭 0~1 / DamageCanvas 1000).
- **A) 그냥 order 밴드** — VFX는 order 50~100(게임플레이 위, 데미지텍스트 아래)에 배치. 추가 세팅 0.
- **B) "VFX" 정렬 레이어 신설** — 더 견고하지만 프로젝트 세팅 변경.
- 권장: **A**(밴드). 지금 규모엔 충분. 나중에 지저분해지면 B.

## 6. 모바일(IL2CPP APK) 주의사항

- **실시간 라이트 끄기:** `CFXR_Effect.GlobalDisableLights = true`로 시작(라이트 연출은 모바일 비용 큼). 필요한 곳만 개별 허용.
- **카메라 흔들림:** `GlobalDisableCameraShake` 있음 — 저사양 대비 전역 제어. 큰 히트에만 의도적으로.
- **HDR 변형은 Bloom 필수:** URP 볼륨에 Bloom 없으면 HDR 프리팹이 칙칙함 → 비-HDR 변형 우선.
- **Screen Distortion 프리팹:** URP opaque-texture/distortion 켜야 보임. 안 켜면 no-op → 당장 스킵.
- **풀링:** 원샷은 `clearBehavior = Disable`로 바꿔 재사용(기본 Destroy는 풀링과 충돌). 상시 루프(불꽃/서리)는 `None` + 적에 부모부착 후 적과 함께 파괴.
- **빌보드/정렬:** 월드공간 3D 빌보드라 자동으로 카메라 향함 OK. 단 스트레치/메쉬형(트레일·배리어·행 라인)은 3D 방향이 있어 2D 투영에서 회전 조정 필요할 수 있음 — 개별 테스트.
- **`+Text` 변형 스킵:** `DamageTextView` 이미 있음.
